# プロフィール設定

## 概要

ユーザーの基本情報・健康プロフィールを入力するモーダル。入力値から健康寿命を自動計算し、カウントダウンや体験予算ゲージに反映する。

## 要件

- [x] ニックネームと生年月日を入力できる（現在年齢をリアルタイムプレビュー）
- [x] 健康プロフィール（性別・喫煙・運動習慣・健康診断結果）を入力できる
- [x] 健康寿命と総寿命を自動計算して表示する
- [x] 手動上書き可能・「計算値に戻す」ボタンがある
- [x] 今年の体験予算（円）を設定できる

## セクション構成

1. **基本情報** — ニックネーム・生年月日（現在年齢プレビュー付き）
2. **健康プロフィール** — 性別・喫煙・運動習慣・健康診断
3. **寿命設定** — 健康寿命 / 総寿命（手動上書き可・計算値に戻すボタン）
4. **体験予算** — 今年の年間体験予算（ダッシュボード予算ゲージに反映）

## 受け入れ基準

- 生年月日入力時に「現在 〇歳」をリアルタイム表示する
- 健康プロフィールの変更時に健康寿命が自動再計算される
- 手動で寿命を変更した場合は自動計算を上書きする（「計算値に戻す」で戻せる）
- 保存はモーダルを閉じる際に localStorage (`z2d_profile`) に書き込む

## 健康寿命の自動計算ロジック

`src/utils/lifeExpectancy.ts` 参照。性別・喫煙・運動習慣・健康診断結果を入力として、日本の平均寿命データをベースに健康寿命を算出する。
