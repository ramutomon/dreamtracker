# タイムライン

## 概要

ユーザーの年齢に対して「あと何年この体験ができるか」を視覚的に示す画面。アクティビティ種別ごとのピーク終了年齢をバーチャートで表示し、今やるべき体験の緊急度を感じてもらう。

## 要件

- [x] アクティビティフェーズ（コア4種）をガントバー形式で表示する
- [x] 現在の年齢位置に縦線（現在地マーカー）を表示する
- [x] バーをクリックすると詳細パネルを表示する
- [x] 各フェーズの「残り〇年」を計算して表示する

## アクティビティフェーズ（コア4種）

| アクティビティ | ピーク終了年齢 |
|---|---|
| ハードな旅行 | 45歳 |
| グルメ・食体験 | 60歳 |
| アクティブスポーツ | 65歳 |
| 一般的な旅行 | 75歳 |

## 受け入れ基準

- 現在年齢がピーク終了年齢を超えているフェーズは「終了済み」として表示する
- 残り年数が3年以内のフェーズは urgent カラー（red-400）で強調する
- 詳細パネルには「このフェーズにやりたいこと」としてバケットリストとの連携ヒントを表示する（Phase 3 で自動化）

## 技術メモ

- Recharts に Gantt チャートが存在しないため、カスタム CSS バーで実装
- `ActivityPhase` の startAge / endAge を使ってバー幅を計算
- フェーズ定義は `src/data/timeline.ts` に集約
