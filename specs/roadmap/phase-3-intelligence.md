# Phase 3 — インテリジェント機能

## 概要

ユーザーの年齢・健康状態・残予算から最適な体験投資順序を提案し、体験をより価値あるものにする機能群。

## 要件

- [ ] サジェストエンジン: 年齢・健康状態・残予算からバケットリストの最適実行順序を提案する
- [ ] 体験予算の年度管理: 月次消費トラッキングとグラフ可視化
- [ ] アクティビティ寿命の個人化: 健康診断データ連携による個人別フェーズ調整

## サジェストエンジン（詳細）

現在の `src/utils/suggest.ts` の `calcPriority()` を拡張する。

入力:
- ユーザーの現在年齢
- 健康状態 (HealthStatus)
- 残体験予算
- 各バケットアイテムの deadline / activityPhaseId

出力:
- 各アイテムの推奨スコア
- 「今年やるべきTop3」のリスト
- 理由文（"あなたの健康状態ならハードな旅行はあと〇年が目安です"）

## アクティビティ寿命の個人化（詳細）

現在のピーク終了年齢（45/60/65/75歳）は一律だが、Phase 3 では:
- 喫煙・運動習慣・健康診断結果から個人ごとにピーク終了年齢を調整
- タイムライン画面に「あなたの場合は〇歳まで」を表示

## 技術メモ

- サジェストエンジンは将来的に AI（Claude API）と連携することを想定した設計にする
- 月次消費トラッキングは Phase 2 の `experience_budgets` テーブルを活用する
